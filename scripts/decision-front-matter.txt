# Sidecar for scripts/split-decisions.sh's front-matter injection.
#
# One block per target path from scripts/decision-map.txt, delimited by
# `=== <path> ===` / `=== end ===`. Block body is copied verbatim between the
# ledger's `<!--` / `-->` front-matter fence — one `key: value` line per line,
# in whatever order and with whatever keys the consumer wants (this file does
# not interpret the keys, only extracts the raw lines).
#
# Task 3 filled every block with real status/scope/read-when/load-when/
# depends-on/related/updated values (see
# docs/superpowers/plans/2026-08-02-decision-ledger-split.md Task 3 Step 1).
# `load-when` keywords are matched against an agent's task description, so
# they are worded as words a task actually uses, not category labels.
# `depends-on: none` marks a file with no prerequisite reading; `related:`
# lists adjacent files worth loading for cross-domain tasks, not implied
# loading for every task that touches this file.
