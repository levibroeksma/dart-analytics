## Identity

- Doubles round the board, counting down: the doubles D1–D20 sum to 420, so
  one hit on each brings you to zero. More hits go negative. Sources:
  dolfdarts.com, "420" (https://dolfdarts.com/games/420, read 2026-10-06);
  named in Winmau's "Top 3 Practice Program"
  (https://winmau.com/blogs/news/top-3-practice-program-to-improve-your-game).
- Standard dartboard scoring: a hit double subtracts its board score (D1 2,
  … D20 40, bullseye 50).

## Exercise type

- Type constant: `DOUBLES_COUNTDOWN` (proposed; not among the seeded types —
  `WARM_UP`, `GAME`, `EXERCISE_SECTION` (`database/seeds/0014_exercise_types.sql`),
  `SWITCHING`, `DOUBLE_PATTERN` (`0016`), `TARGET_SCORING` (`0023`),
  `SWITCHING_TARGET_SCORING` (`0024`), `SCORE_THRESHOLD` (`0025`),
  `BULLSEYE_CHECKOUT` (`0029`), `BULL_UP` (`0030`)).
- Wraps no game. Bob's 27 walks the same D1 → D20 → bull path, three darts
  each, but adds hits to 27, subtracts on a blank visit and can end early
  (`docs/game-rules/rulesets/bobs-27.md` §Identity). 420 never ends early.
- Behaviour no existing type provides: a fixed one-visit-per-target walk
  whose readout is a countdown of board scores.

## Objective

- Finish as far below zero as possible.
- Source benchmarks: 0 is one hit per target; below zero is better; −990 is
  perfect (every dart hits).

## How to practise

**Single:** one player per run.

**1v1:** each player plays all 21 rounds; lower remaining wins (V2+).

### Visit

- Three darts at the round's double (the bullseye in round 21). All three
  are thrown.
- Each dart in the target double subtracts that double's board score from
  the **remaining**. In round 21 only the bullseye counts, not the outer
  bull: "the inner bullseye in round 21" (source).

### Progress

- After every visit, the next round, hit or not.

### Bound

- **Run ends after round 21.**
- **Time-bound run** inside a routine; the routine's allocated duration
  overrides the default (`EXERCISE_TEMPLATE.md` §Bound).

## Later versions

### Variants

- **Range-Focused 420** — only the player's weak doubles.
- **Treble 420** — trebles instead of doubles.
- **Competitive 420** — two players, lower remaining wins.

### Other

- **Standalone entry** — see Features row.

## Capture

- **Capture / input mode:** analytics mode under the `ANALYTICS` +
  `VISUAL_BOARD` capture pair, as the shipped exercises
  (`docs/architecture/09-Training/01-Routines.md` §Bullseye Checkouts).
- **One dart's fact:** one `darts` row per throw. Intended target and zone
  as `doubleTargetIntent` records for a doubles path: the number and
  `DOUBLE`, or 25 and `INNER_BULL` in round 21
  (`app/src/modules/game/turn-log.module.ts:103`). `score` is the dart's
  **board** score (`appendObservedDart`, same file:134).
- **Stage type:** one `EXERCISE_BLOCK` stage per run (`exerciseBlockStage()`,
  `app/src/modules/game/turn-log.module.ts:118`); one `turns` row per round.
- **Derived, never stored:** hit or miss per dart, remaining (420 minus the
  board scores of hit darts), hits per double, hit rate.
- The remaining is a fold over board scores, not a conventional game score.
