**Multiplayer, as implemented (2026-08-21):** a session seats 1-4 participants

## Identity

One of the classic darts games: race from a starting score down to exactly zero. Standard dartboard scoring is assumed. Sibling start scores (301, 701, or a custom 2–999 value) are selectable at setup; alternate in/out rules exist as later variants.

## Objective

- **Leg:** reduce your score from the start total to **exactly 0**, finishing on a **double** (double out, including double bull).
- **Session (V1):** **first to N** legs — win N legs to finish the session. Each new leg starts fresh from the start score.

## How to play

### Visit

A **visit** is one turn at the board: the player may throw **up to three darts**. After those darts, the visit ends and play passes to the next player. In single-player (V1), that still means one visit at a time — finish the visit, then start the next.

If the leg is won on the first or second dart (a successful checkout), the visit **ends immediately** — the remaining darts are not thrown.

### Progress

Each scoring dart subtracts from the remaining total. Play continues visit by visit until the player checks out or busts.

### Finishing

Under V1 **double out**, **the dart that reaches exactly 0** must itself be a double (including double bull). That wins the leg.

This is about the finishing dart specifically, not about the visit. A visit that puts one dart in a double and then reaches 0 on a single is **not** a checkout — it is a bust. Darts thrown at a double that did not finish the leg are tracked separately as practice statistics; they never win it. <!-- resolved 2026-07-26 -->

### Bust

If a visit would take the player past 0, or leave a score that cannot be finished under the active out rule (for example, remaining on 1 when the game must end on a double), that visit is a **bust**. The darts in that visit do not count; the player’s score goes back to what it was at the start of the visit, and the turn is over.

### Ends when

The session ends when one side has won **N legs**, N being the configured
`legs_to_win` (default 1, max 20). Nothing outside the game bounds it — there is
no clock and no round budget.

**Single:** the one seat wins every leg it checks out; the session ends on its
Nth.

**2+:** each leg is shared — one stage holds every seat's interleaved visits —
and legs fold per `sideKey`. The first side to N legs ends the match
immediately; the other seats do not finish the leg in progress.

With sets on (V2), a set ends when one side reaches its leg target for that
set (under Win by 2 legs, see Later versions), and the session ends when one
side has won its set target. Best of N ends at first to (N+1)/2 — the
remaining legs or sets are not played.

### Result

With sets on (V2), the set score against each other side leads, followed by
the leg score of every set.

The winning side, its leg count against each other side, and per side: darts
thrown, 3-dart average, and best leg.

## Later versions

### Variants

- Alternate **in / out** modes — defined in the Glossary; **not selectable in V1**

### Match structure

- **Best of N legs** (V2) — odd N only; identical to first to (N+1)/2, at any
  side count. A match is never drawn.
- **Sets** (V2) — first to S sets / best of S sets (odd S only). Each set is a
  leg race of its own; a set won counts 1 toward the match, and every set
  starts with legs at 0-0 and every seat at the start score.
- **Sets of 3 or 5 legs** (V2) — the set-length presets: best of 3 legs (first
  to 2) and best of 5 legs (first to 3). Any first to / best of L is allowed.
- **Win by 2 legs** (V2) — optional. A leg race that reaches its target
  without a 2-leg lead over every other side plays on until one side leads
  every other side by 2. With sets off it governs the match's leg race; with
  sets on, each set's leg race (see Deciding-set margin).
- **Sudden-death leg** (V2) — bounds Win by 2 legs. The cap X is set as
  "sudden death at X-X"; the first side to reach X + 1 legs wins the race,
  margin or not. With two sides that is the leg played from X-X. X defaults
  to target + 2 (first to 3 → sudden death at 5-5) and is never below the
  target.
- **Deciding-set margin** (V2) — with sets and Win by 2 legs on, the player
  picks whether the margin applies to every set or only to the deciding set
  (the set played when every side stands one set short of the set target).
- **Per-set throw rotation** (V2) — with sets on, set k's first leg opens on
  seat k (wrapping at the seat count) and the legs inside a set rotate from
  there. With sets off, the leg rotation in Features is unchanged.

**2+:** under Win by 2 legs with three or four sides, the lead is measured
against every other side, not only the runner-up.

## Glossary

| Term                    | Version | Meaning                                                                                                 |
| ----------------------- | ------- | ------------------------------------------------------------------------------------------------------- |
| **Open in**             | V1      | Every dart counts from the start of the leg.                                                            |
| **Double out**          | V1      | The finishing dart must be a double (including double bull).                                            |
| **Double in**           | V2+     | The leg does not start counting until the player hits a double. Darts before that double score nothing. |
| **Master in**           | V2+     | Same idea as double in, but the opening hit must be a master: a double, a triple, or the bull.      |
| **Master out**          | V2+     | The finishing dart must be a master: a double, a triple, or the bull.                                   |
| **Straight / open out** | V2+     | The leg can be finished on any dart that reaches exactly 0 (no double/master required).                 |
| **First to N**          | V1      | Session ends when one side has won N legs.                                                              |
| **Best of N**           | V2      | Odd N only; the match ends at first to (N+1)/2.                                                         |
| **Sets**                | V2      | A match of S sets, each a leg race of its own.                                                          |
| **Win by 2 legs**       | V2      | A leg race plays on past its target until one side leads every other side by 2.                        |
| **Sudden-death leg**    | V2      | Past the configured cap X, the first side to X + 1 legs wins a Win by 2 legs race.                      |
| **Deciding-set margin** | V2      | Win by 2 legs applied only to the set that decides the match.                                           |
| **Per-set throw rotation** | V2   | Set k's first leg opens on seat k; legs inside the set rotate from there.                               |

## Capture

- **Capture / input mode:** RECREATIONAL + QUICK_SCORE — one visit total per turn, **no dart rows**. Also implemented: ANALYTICS + VISUAL_BOARD — one dart at a time, board score per dart, real landing coordinates.
- **One dart's fact (VISUAL_BOARD only):** `score` = the dart's own board score; a busted visit keeps its real dart rows with `totalScore` reset to `0` — the divergence between the two is what makes bust rate computable under this mode (see Known limitations). QUICK_SCORE records no darts at all; the unit of capture there is the visit.
- **Stage type:** one `LEG` per leg. A won leg opens the next. With sets on (V2), one `SET` stage per set, each holding its legs as child `LEG` stages (`parentClientKey` = the set, `sequence` = the leg's position in the set); a won set opens the next. With sets off, legs stay root stages.
- **Derived, never stored:** the remaining score, leg wins, and averages — all folded from the visit totals (or dart totals, under VISUAL_BOARD).

## Known limitations

**Under RECREATIONAL + QUICK_SCORE, a bust cannot be told apart from a scoreless visit.** A busted visit and a genuine zero-scoring visit are both persisted as a turn total of `0` with no dart rows. Nothing in the stored record distinguishes them. Consequences:

- **Bust rate is not computable at all under this capture mode.**
- **Checkout percentage undercounts attempts** — a busted checkout attempt looks exactly like a visit in which nothing counted, so it never enters the denominator.

Recovering either requires DETAILED_DARTS/VISUAL_BOARD capture or a schema revision adding an attempted-score or void-visit fact for QUICK_SCORE itself; QUICK_SCORE sessions remain unfixable, since completed gameplay is immutable and no per-dart fact exists to recover from. <!-- 2026-07-26 -->

**Retired for ANALYTICS + VISUAL_BOARD sessions.** Every dart carries a real landing coordinate and score, so a bust and a plain miss are distinguishable by the pattern in the persisted darts: a bust's darts show an overshoot, a remaining score of exactly 1, or reaching 0 without the last dart in a double; a miss's darts land short of a double with none of those patterns. No `v_*` view yet queries this distinction — the fact log supports it, and building the view is future work.
