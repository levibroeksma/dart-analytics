## Identity

Checkout and counting practice built on X01-style scoring. Start at **121**, try to finish to 0 within a limited dart budget; success climbs the target (122, 123, …). Standard dartboard scoring is assumed; finishing is double out.

## Objective

- **Attempt:** from the current target score, reach **exactly 0** on a **double** within the allowed darts (3, 6, or 9).
- **Session (V1):** keep climbing after each success. Failure handling depends on difficulty (see config / later versions).
- **1v1:** first to check out 170 wins; the match ends immediately (race). <!-- 2026-08-22 -->

## How to play

### Visit

A **visit** is up to **three darts**. The dart budget is a set number of visits (e.g. 9 darts = three visits). Scoring works like X01: subtract each dart from the remaining total.

### Progress

Begin at **121**. Within the dart budget, try to check out. On success, the next attempt starts at **current + 1** (122, then 123, and so on).

### Finishing

Must reach exactly 0 on a double (including double bull), same idea as 501 double out.

### Bust

If a visit would go past 0, leave 1 under double out, or hit 0 without a double, that visit is a **bust**: those darts do not count; score returns to the start of the visit. Remaining visits in the budget (if any) continue from that restored score.

**Early bust on the attempt's final visit (V1, ANALYTICS + VISUAL_BOARD).** On the 3rd (final) visit of an attempt, once the remaining score can no longer be checked out within the darts still left in that visit — read off the standard checkout chart, not merely an odd/even check — the visit busts immediately instead of requiring every dart to be thrown. This is 121-specific: the attempt's first two visits never take this branch, and 501 still requires every dart in a visit to be thrown regardless of whether a checkout remains mathematically possible.

### Failure (end of budget)

If the checkout is not made within the dart budget, apply the fail rule. V1 easy: **stay** on the current target and try again.

### Ends when

Three stop conditions, picked on the config screen (V2; V1 has only the first):

- **Target** — the ladder reaches the cap, **170**, and that attempt checks out.
- **Rounds mode** — the attempt budget runs out: **N** attempts, 1–50.
- **Timed mode** — the clock runs out: **M** minutes, 3–30. The attempt in
  progress finishes first.

**Single:** the one seat plays until its own stop condition is met.

**1v1:** the Target stop condition is a race — the first seat to check out the
cap wins and the match ends immediately, so the trailing seat never gets
another turn. 1v1 is a V1-only ruleset; a V2 session (Rounds or Timed) seats
one player.

### Result

The highest target reached, attempts made, checkouts hit and missed, and — on a
Target session — whether the cap was reached. In 1v1, the winning seat beside
the same numbers for both.

## Later versions

### Variants

- Dart budget selectable: **3 | 6 | 9**
- Fail rules:
  - **Easy:** stay on current number
  - **Hard:** move back **1**
  - **Extreme:** reset to **121**
- Optional **safehouse**: a 3-dart checkout locks a floor so you cannot drop below that score later
- Optional climb cap / win when a chosen end target is checked out

### Match structure

- Multiplayer: players alternate attempts; race or shared ladder as product defines

## Glossary

| Term             | Version  | Meaning                                                                |
| ---------------- | -------- | ---------------------------------------------------------------------- |
| **Dart budget**  | V1 / V2+ | How many darts allowed per attempt at the current target (3, 6, or 9). |
| **Easy fail**    | V1       | Miss the budget → stay on the same target.                             |
| **Hard fail**    | V2+      | Miss the budget → target decreases by 1.                               |

## Capture

- **Capture / input mode:** RECREATIONAL + QUICK_SCORE — one visit total per turn, **no dart rows**. Also implemented: ANALYTICS + VISUAL_BOARD — one dart at a time, board score per dart, real landing coordinates.
- **One dart's fact (VISUAL_BOARD only):** `score` = the dart's own board score; a busted visit keeps its real dart rows with `totalScore` reset to `0`. QUICK_SCORE records no darts at all; the unit of capture there is the visit.
- **Stage type:** one `ROUND` per attempt. A resolved attempt that doesn't end the match (a checkout short of the cap target, or a failure under easy fail) opens the next round.
- **Derived, never stored:** the ladder position (`currentTarget`), the live countdown within the open attempt (`remainingInAttempt`), and visit counts — all folded from the turn totals (or dart totals, under VISUAL_BOARD).
