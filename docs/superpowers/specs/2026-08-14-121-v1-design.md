# 121 V1 — Design Spec

## Summary

New single-player game type: X01-style checkout ladder. Start at target **121**, try to check out to exactly 0 on a double within a **9-dart budget** (3 visits of 3 darts). Success climbs the target by 1 (122, 123, …); failure (budget exhausted without checkout) applies the v1 fail rule — **stay** on the current target and try again. A climb cap ends the session: checking out target **170** wins.

Source: `docs/game-rules/rulesets/121.md` (non-canonical). Its Features table left dart budget 3/6 and harder fail rules (`hard`/`extreme`) as `TBD` — v1 ships only the 9-dart budget and the easy/stay fail rule, per the doc's own V1 preset table.

## Scope

**V1 ships:**

- Single player
- Config screen shown, all settings locked: start target 121, double out, 9-dart budget (3 visits × 3), fail rule = stay, cap/end target 170
- X01-style visit scoring with standard bust rules (overshoot, leave-1, reach-0-without-double)
- `RECREATIONAL` + `QUICK_SCORE` capture (visit total + "finished on double", keypad input — no dart rows)
- Session completes on checking out target 170

**Deferred (not this branch):** multiplayer, selectable dart budget (3/6), hard/extreme fail rules, safehouse floor, configurable cap, DETAILED_DARTS/VISUAL_BOARD capture.

## Persistence shape (Hard Invariant)

- Capture mode: `RECREATIONAL`; input mode: `QUICK_SCORE`
- Stage type: one `ROUND` stage per attempt at a target (first use of the existing but previously-unused `ROUND` `StageTypeKey`). A `ROUND` holds 1–3 turns (visits) and closes when the attempt resolves — checkout or a 3rd failed visit.
- On fail-rule "stay", the next attempt opens a **new** `ROUND` stage at the same target (mirrors 501 opening a new `LEG` stage per leg).
- Turns: one `TurnFact` per visit, `totalScore` = the visit's scored total (0 on a bust), `darts: []` — quick-score, no dart rows (same as 501/TUOD; bust rate is therefore not separately computable, same known limitation as TUOD).
- No `intendedTargetNumber`/`intendedZoneKey`/dart facts at all in v1 (no DETAILED_DARTS/VISUAL_BOARD capability).

## Engine (`modules/game/one-twenty-one.engine.module.ts`)

```ts
const START_TARGET = 121;
const CAP_TARGET = 170;
const DARTS_PER_VISIT = 3;
const VISITS_PER_ATTEMPT = 3;

type OneTwentyOneVisitInput = {
  scoreAttempted: number;
  finishedOnDouble?: boolean;
};

type OneTwentyOneState = {
  currentTarget: number;      // 121..170
  visitsThisAttempt: number;  // 0..3, resets when a ROUND closes
  status: "IN_PROGRESS" | "WON";
};
```

`resolveOneTwentyOneVisit(remainingInAttempt, input)` — same bust matrix as `FiveOhOneEngine`'s private `resolveFiveOhOneVisit` (independent module, same shape, not shared code): an overshoot busts; leaving exactly 1 busts; reaching exactly 0 without `finishedOnDouble` busts.

`applyOneTwentyOneVisit(state, input)`:

- Checkout (reaches 0 on a double): if `currentTarget === CAP_TARGET` → `status: "WON"`; else `currentTarget + 1`, `visitsThisAttempt: 0`, new `ROUND`.
- Bust/miss with `visitsThisAttempt < VISITS_PER_ATTEMPT - 1`: attempt continues, `visitsThisAttempt + 1`, remaining score in the `ROUND` carries to the next visit (same `ROUND`, same target).
- Bust/miss on the 3rd visit (`visitsThisAttempt === VISITS_PER_ATTEMPT - 1`): fail rule applies — `currentTarget` unchanged (v1: stay), `visitsThisAttempt: 0`, new `ROUND` at the same target.
- Throws if called when `status !== "IN_PROGRESS"` (same contract as every other engine).

`remainingInAttempt` for a visit is derived the same way 501 derives `remainingBeforeVisit`: `currentTarget - sum(totalScore of prior turns in the same ROUND)`.

`OneTwentyOneEngine implements GameEngine<OneTwentyOneVisitInput, OneTwentyOneState>` — same member shape as `FiveOhOneEngine` (`record`/`undo`/`wouldComplete`/`isComplete`/`state`/`facts`/`create(config, prior)`), with `ROUND` open/close logic replacing 501's `LEG` open/close logic and a climb-to-cap in place of a legs-to-win counter. `undo()` is the exact inverse over turns and `ROUND` stages, mirroring `FiveOhOneEngine.undo()`'s dispatch (pop last turn; pop the `ROUND` stage only if the popped turn was the one that opened it).

Registered in `modules/game/engine.registry.ts` under `121_V1`. Server-side validator under `services/rulesets/one-twenty-one/`, registered in `services/rulesets/registry.ts`, enforcing `RECREATIONAL`+`QUICK_SCORE` only — same commit as the engine, per `scripts/check-game-engines.sh`'s pre-commit gate.
