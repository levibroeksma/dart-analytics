# Shanghai V3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `SHANGHAI_V3`: selectable round range presets (1–7, 1–10, 1–20, 11–20, 13–20) and a Score-only mode (instant win off), composing with Normal/Hard.

**Architecture:** A new ruleset version beside untouched V1/V2 (D245). The seat state carries `rangeStart`, `rangeEnd`, `instantWin`, so consumers that only hold a seat need no config threading; three engine helpers (`activeNumberOf`, `roundOf`, `roundCountOf`) are the single home of the range math. No migration; a seed row plus capability rows.

**Tech Stack:** TypeScript, Zod, Vitest, Alpine.js, Astro, PostgreSQL seeds.

**Spec:** `docs/superpowers/specs/2026-10-25-shanghai-v3-design.md`. Rules: `docs/game-rules/rulesets/shanghai.md`.

## Review Focus

- Round-9 dart in a 13–20 session (index past the range end) is refused, not silently targeting 21/BULL.
- A single-round range (`rangeStart === rangeEnd`) plays one visit and ends.
- Score-only 1v1 with equal totals ends `TIE`, not a win and not `IN_PROGRESS`.
- Hard blank round in 11–20 halves the running total (range does not change the penalty).
- Play again from a V3 session keeps range, win rule and difficulty; Play again from V1 stays V1.
- The `shanghai-count` histogram keys a Shanghai on 13–20 by the number (13…20), and Score-only sessions do not enter its denominator.

function shanghaiRules(settings: ShanghaiSettings): TrackRules<ShanghaiTrackExt> {
  const path = PATH.slice(settings.rangeStart - 1, settings.rangeEnd);
  const advance = advanceToEnd<ShanghaiTrackExt>(path.length - 1);
  const halve: (seat: TrackSeat<ShanghaiTrackExt>) => TrackSeat<ShanghaiTrackExt> =
    settings.difficulty === "HARD" ? halveOnBlank : (seat) => seat;
  const judge = settings.instantWin ? shanghaiWin : (seat: TrackSeat<ShanghaiTrackExt>) => seat;
  return {

    target: pathTarget(path),
    hit: anyRingEitherBull,
    points: boardScorePoints,
    onDart: recordVisitZone,
    visitOpen: closeAfter(3),
    onVisitClose: (seat) => {
      const judged = judge(halve(seat));
      const moved = judged.status === "IN_PROGRESS" ? advance(judged) : judged;
      return { ...moved, ext: { ...moved.ext, zones: [] } };

}
