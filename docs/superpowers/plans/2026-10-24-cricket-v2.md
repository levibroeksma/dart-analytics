## Review Focus

1. Excess marks on the closing dart score only while the opponent has the number open; zero otherwise (Task 2).
2. The winning dart ends the game mid-visit: no further dart accepted, `completedAt` stamped, no hand-over after it (Task 2).
3. A closed-out seat that is behind keeps throwing and scores on numbers the opponent has open; either seat closing out level or ahead wins; no tie (Task 2).
4. Undo of a winning, a scoring and a dead-making dart restores the earlier state (Task 2).
5. A V1 solo log folds as before apart from `points: 0`; V2 solo folds as V1; Tactics behaviour is unchanged by the Task 3 extraction (Tasks 2, 3).
6. Guest opponent is selectable from setup and starts `CRICKET_V2`; no DartBot control; solo starts `CRICKET_V1` (Task 4).
7. Resume mid-game in either seat's turn; the resume deck keeps a V2 session on the Cricket card; V1 sessions replay unchanged (Tasks 4, 5).
8. Seven rows with two pip groups fit the 40% band at 390px and the switch animation fires on every hand-over (Task 6 visual check).

  facts: EngineFacts,
  config: Seated<CricketSnapshot>,
): CricketState {

    .participantRef;

    const duel = foldMarksDuel(
      facts.turns,
      [config.seats[0], config.seats[1]],
      CRICKET_DUEL,
    );
    return {
      activeParticipantRef: duel.winnerParticipantRef ?? activeParticipantRef,
      status: duel.winnerParticipantRef === null ? "IN_PROGRESS" : "COMPLETE",
      winnerParticipantRef: duel.winnerParticipantRef,
      seats: duel.seats,
    };
  }
  const seats = foldSeatStates(
    facts.turns,
    config.seats,
    initialSeatState,
    applyCricketDart,
  );
  return {
    activeParticipantRef,
    status: seats.every((seat) => seat.status === "COMPLETE")
      ? "COMPLETE"
      : "IN_PROGRESS",
    winnerParticipantRef: null,
    seats,
  };
}
