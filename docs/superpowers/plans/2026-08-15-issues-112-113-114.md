# Issues #112, #113, #114 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship three small, independent UI fixes on one branch: uppercase recreational game-input text (#112), Singles Training session-summary stats (#113), and a back button on every setup page (#114).

**Architecture:** Pure display-layer changes over already-recorded facts and already-existing components — no engine, schema, store, or API change. #112 is a literal-text edit. #113 widens an existing `resultsSnapshot` builder and adds `StatRow`s to an existing modal. #114 adds one optional prop to the shared `AppLayout` and threads it through 8 setup pages.

**Tech Stack:** Astro, TypeScript, Alpine.js, Vitest.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-08-15-issues-112-113-114-design.md` — this plan implements it in full; no requirement deviates.
- `.astro` markup changes are not unit-tested (D101, `app/CLAUDE.md`) — verify those with `npm run check` (type-check) and a visual/grep check, not a new test file.
- `.ts` changes follow TDD: failing test → minimal implementation → passing test (`app/CLAUDE.md` Test-Driven Development).
- No `//` or `/* */` comments inside TypeScript function/method bodies (`app/CLAUDE.md` TypeScript comments rule); JSDoc above a declaration only.
- Tailwind v4 semantic tokens only (`text-muted`, `text-foreground`, etc.) — never raw palette utilities; suffix `!important` never prefix (`app/CLAUDE.md` Style non-negotiables).
- A standalone action always renders through `components/forms/Button.astro` — never a raw `<button>` (`app/CLAUDE.md` Style non-negotiables).
- Alpine v3 shorthand only: `@click`, `:attr` — never `x-on:`/`x-bind:` (`app/CLAUDE.md` Frontend Rules).
- Run `cd app && npm run format` before any commit that touches `.astro`/`.ts` files and confirm `npm run format:check` is clean (`app/CLAUDE.md` Formatting).
- Tests live under `app/tests/`, mirroring `app/src/`'s structure — never colocated (`app/CLAUDE.md` TDD rules).

to:
```typescript
    uploadAndCompleteSession(this: SinglesTrainingPlayContext): Promise<void> {
      return playUploadAndCompleteSession(this, (finalState) => {
        const turns = this.$store.game.turns;
        const misses = countZoneKey(turns, MISS_COUNT_ZONE_KEYS);
        const singles = countZoneKey(turns, SINGLE_COUNT_ZONE_KEYS);
        const doubles = countZoneKey(turns, DOUBLE_COUNT_ZONE_KEYS);
        const trebles = countZoneKey(turns, TREBLE_COUNT_ZONE_KEYS);
        const hits = singles + doubles + trebles;
        const darts = hits + misses;
        return {
          points: finalState.totalPoints,
          misses,
          singles,
          doubles,
          trebles,
          hitPercentage:
            darts === 0 ? "0%" : `${Math.round((hits / darts) * 100)}%`,
        };
      });
    },
```

- [ ] **Step 2: Replace with the back-button-aware version**

Replace the full file contents with:
```astro
---
import BaseLayout from "@layouts/BaseLayout.astro";
import BottomNav from "@components/layout/BottomNav.astro";
import Button from "@components/forms/Button.astro";
import ChevronDownIcon from "@icons/chevron-down.svg";

interface Props {
  title?: string;
  showBackButton?: boolean;
}

const { title, showBackButton = false } = Astro.props;
---

<BaseLayout title={title}>
  <div class="mx-auto flex h-full max-w-lg flex-col">
    {
      showBackButton ? (
        <header class="flex items-center pt-3">
          <Button
            type="button"
            variant="ghost"
            icon
            ariaLabel="Back to games"
            @click="globalThis.location.href = '/games'"
          >
            <ChevronDownIcon
              class="size-6 text-muted rotate-90"
              slot="iconBefore"
            />
          </Button>
        </header>
      ) : null
    }
    <main
      class="flex min-h-0 flex-1 flex-col overflow-y-auto overscroll-y-contain"
    >
      <slot />
    </main>
    <BottomNav />
  </div>
</BaseLayout>
```

(The `rotate-90` class turns `chevron-down.svg`'s down-pointing chevron into a left-pointing "back" chevron — the same reuse-by-rotation `InfoSection.astro` already applies to the same icon with `-rotate-90` for its own right-pointing collapsed state. No new icon asset.)
