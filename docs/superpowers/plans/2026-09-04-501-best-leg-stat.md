# 501 "Best Leg" Stat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show a "Best leg" stat (fewest darts to win a leg) on the 501 1v1 match-summary comparison view, with "—" for a side that never won a leg.

**Architecture:** A new pure function `legResultsOf` in the 501 engine module folds the fact log leg-by-leg (reusing the existing private `foldLeg` helper) into each completed leg's winner and dart count. `five-oh-one-play.data.ts`'s `buildResultsSnapshot` calls it once and derives each seat's minimum into a new `bestLeg: string` field on `FiveOhOneSeatResult`. `FiveOhOneResults.astro` renders it as one more row, but only for the 1v1 `ComparisonSummary` — the shared `STAT_ROWS` used by the solo summary is untouched.

**Tech Stack:** TypeScript, Astro, Vitest.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-09-04-501-best-leg-stat-design.md`
- "—" (em dash, `U+2014`) is the missing-value marker — never a literal `-` hyphen. It matches `checkoutPercentage`'s fallback and `previousScoreDisplay`'s convention already in this codebase.
- Per-visit dart count: `turn.darts.length` when non-zero (VISUAL_BOARD — exact), else `config.maxDartsPerTurn` (QUICK_SCORE — the same approximation `dartsThrownCount` already uses). Quick-score turns never carry dart rows, by existing documented design — do not change that.
- Solo (`SinglePlayerSummary`) games are out of scope — do not touch `STAT_ROWS` in `FiveOhOneResults.astro`.
- No schema/migration changes. No new persisted facts.
- `app/CLAUDE.md`: any modified runtime `.ts` file under `app/src/` needs a covering test edit in the same change set (`scripts/check-test-coverage.sh`). Type-only edits are exempt.
- Run `cd app && npm run format` before considering any task's diff final.

```ts
function legDartsFor(
  participantRef: string,
  visits: readonly TurnFact[],
  maxDartsPerTurn: number,
): number {
  return visits
    .filter((visit) => visit.participantRef === participantRef)
    .reduce(
      (sum, visit) =>
        sum + (visit.darts.length > 0 ? visit.darts.length : maxDartsPerTurn),
      0,
    );
}

export function legResultsOf(
  facts: EngineFacts,
  config: Seated<FiveOhOneSnapshot>,
): LegResult[] {
  const remaining = new Map<string, number>();
  const results: LegResult[] = [];

  for (const stage of facts.stages) {
    const visits = legVisitsOf(facts, stage);
    const winner = foldLeg(visits, config, remaining);
    if (winner === null) continue;

    results.push({
      sideKey: winner.sideKey,
      participantRef: winner.participantRef,
      darts: legDartsFor(
        winner.participantRef,
        visits,
        config.maxDartsPerTurn,
      ),
    });
  }

  return results;
}
```

`EngineFacts`, `Seated`, and `FiveOhOneSnapshot` are already imported at the top of this file; only `LegResult` needs adding to the existing `from "./types"` block.

```ts
function bestLegFor(
  participantRef: string,
  legResults: readonly LegResult[],
): string {
  const darts = legResults
    .filter((result) => result.participantRef === participantRef)
    .map((result) => result.darts);
  return darts.length > 0 ? String(Math.min(...darts)) : "—";
}
```

Update `statsFor`'s signature and return value:

```ts
function statsFor(
  seat: SeatFact,
  turns: readonly TurnFact[],
  legsWon: number,
  maxDartsPerTurn: number,
  inputModeKey: string | null,
  legResults: readonly LegResult[],
): FiveOhOneSeatResult {
  const seatTurns = turns.filter(
    (turn) => turn.participantRef === seat.participantRef,
  );
  return {
    participantRef: seat.participantRef,
    sideKey: seat.sideKey,
    legsWon,
    threeDartAverage: threeDartAverageDisplay(seatTurns, maxDartsPerTurn),
    checkoutPercentage:
      inputModeKey === "VISUAL_BOARD"
        ? accuracyDisplay(legsWon, legsWon + checkoutAttemptCount(seatTurns))
        : null,
    ...visitScoreBandCounts(seatTurns),
    bestLeg: bestLegFor(seat.participantRef, legResults),
  };
}
```

Update `buildResultsSnapshot`:

```ts
function buildResultsSnapshot(
  context: FiveOhOnePlayContext,
): FiveOhOneResultsSnapshot {
  const seats = context.$store.game.seats;
  const config = context.$store.game.configSnapshot;
  const maxDartsPerTurn = config?.maxDartsPerTurn ?? 3;
  const inputModeKey = context.$store.game.inputModeKey;
  const legResults = config
    ? legResultsOf(
        {
          stages: context.$store.game.stages,
          turns: context.$store.game.turns,
        },
        config,
      )
    : [];
  return {
    winningSideKey:
      seats.length >= 2 ? (context.state()?.winningSideKey ?? null) : null,
    seats: seats.map((seat) =>
      statsFor(
        seat,
        context.$store.game.turns,
        context.legsWonFor(seat.participantRef),
        maxDartsPerTurn,
        inputModeKey,
        legResults,
      ),
    ),
  };
}
```
