# Bob's 27 Engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the pure-logic Bob's 27 game engine (V1 Traditional, single player) — target progression, scoring, win/loss detection, and one-dart-back undo — with no UI, persistence, or config/session wiring.

**Architecture:** A pure reducer `applyDart(state, hit)` holds all scoring/progression rules and is unit-tested in isolation. A `Bobs27Engine` class wraps it with the same call-site shape as the existing `ScoreTrainingEngine`, adding a history stack for undo. Everything lives in `app/src/modules/game/`, following the existing module-per-game-engine convention.

**Tech Stack:** TypeScript, Vitest (`app/vitest.config.ts`, `@modules` path alias → `app/src/modules`).

## Global Constraints

- Spec of record: `docs/superpowers/specs/2026-07-24-bobs27-engine-design.md`.
- Starting score: 27. Path: DOUBLE 1 → DOUBLE 20 → BULL (21 visits total, 3 darts each).
- `BULL` scores as 50 (inner/"double" bull only); outer bull (25) counts as a miss.
- Hits add to score **immediately**, per dart, as they happen. A full-miss visit (all 3 darts miss) subtracts the target's value **once**, only once the 3rd dart resolves the visit.
- Score `<= 0` at visit-resolution → `LOST`. Positive score after the bull visit resolves → `WON`. `LOST` takes priority over `WON` when both conditions would fire on the same (bull) visit.
- `undoLastDart()` reverts exactly one dart at a time, including across visit boundaries and past a game-ending dart (status reverts to `IN_PROGRESS`).
- No `.ts` file comments inside function/method bodies (`app/CLAUDE.md`); JSDoc above declarations only where the "why" is non-obvious.
- TDD mandatory: tests under `app/tests/modules/game/`, written before implementation, `npm test` run from `app/`.
- Out of scope (do not implement): UI, persistence to `turns`/`darts`, `configuration_templates`/`ruleset_versions` wiring, Easy/multiplayer/DartBot variants, session lifecycle.

```ts
import type { Bobs27State, Bobs27Target } from "./types";
import { BULL_HIT_VALUE } from "./types";

function targetForIndex(targetIndex: number): Bobs27Target {
  return targetIndex < 20 ? { kind: "DOUBLE", number: targetIndex + 1 } : { kind: "BULL" };
}

function targetValue(target: Bobs27Target): number {
  return target.kind === "DOUBLE" ? target.number : BULL_HIT_VALUE;
}

export function initialBobs27State(startingScore: number): Bobs27State {
  return { targetIndex: 0, score: startingScore, dartsThisVisit: [], status: "IN_PROGRESS" };
}

export function applyDart(state: Bobs27State, hit: boolean): Bobs27State {
  if (state.status !== "IN_PROGRESS") {
    throw new Error("Cannot record a dart once the game has ended; undo first to correct it.");
  }

  const target = targetForIndex(state.targetIndex);
  const dartsThisVisit = [...state.dartsThisVisit, hit];
  const score = hit ? state.score + targetValue(target) : state.score;

  if (dartsThisVisit.length < 3) {
    return { ...state, score, dartsThisVisit };
  }

  const visitHits = dartsThisVisit.filter(Boolean).length;
  const resolvedScore = visitHits === 0 ? score - targetValue(target) : score;

  if (resolvedScore <= 0) {
    return { ...state, score: resolvedScore, dartsThisVisit: [], status: "LOST" };
  }
  if (target.kind === "BULL") {
    return { ...state, score: resolvedScore, dartsThisVisit: [], status: "WON" };
  }
  return {
    ...state,
    score: resolvedScore,
    dartsThisVisit: [],
    targetIndex: state.targetIndex + 1,
  };
}
```

```ts
export class Bobs27Engine {
  private state: Bobs27State;

  constructor(startingScore: number = BOBS27_START_SCORE) {
    this.state = initialBobs27State(startingScore);
  }

  recordDart(hit: boolean): Bobs27State {
    this.state = applyDart(this.state, hit);
    return this.state;
  }

  currentTarget(): Bobs27Target {
    return targetForIndex(this.state.targetIndex);
  }

  currentScore(): number {
    return this.state.score;
  }

  isGameOver(): boolean {
    return this.state.status !== "IN_PROGRESS";
  }

  result(): "WON" | "LOST" | null {
    return this.state.status === "IN_PROGRESS" ? null : this.state.status;
  }
}
```

```ts
export class Bobs27Engine {
  private state: Bobs27State;
  private history: Bobs27State[] = [];

  constructor(startingScore: number = BOBS27_START_SCORE) {
    this.state = initialBobs27State(startingScore);
  }

  recordDart(hit: boolean): Bobs27State {
    this.history.push(this.state);
    this.state = applyDart(this.state, hit);
    return this.state;
  }

  /** Reverts exactly the last recorded dart, one at a time, even across visit/game-over boundaries. */
  undoLastDart(): boolean {
    if (this.history.length === 0) return false;
    this.state = this.history.pop()!;
    return true;
  }

  currentTarget(): Bobs27Target {
    return targetForIndex(this.state.targetIndex);
  }

  currentScore(): number {
    return this.state.score;
  }

  isGameOver(): boolean {
    return this.state.status !== "IN_PROGRESS";
  }

  result(): "WON" | "LOST" | null {
    return this.state.status === "IN_PROGRESS" ? null : this.state.status;
  }
}
```

(Only `recordDart` gains the `this.history.push(...)` line and the class gains the `history` field and `undoLastDart` method; `constructor`, `currentTarget`, `currentScore`, `isGameOver`, `result` are unchanged from Task 2.)
