# IconBtn.astro Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `app/src/components/forms/IconBtn.astro`, a dedicated icon-only button primitive that is always a true circle, per the approved spec `docs/superpowers/specs/2026-08-21-iconbtn-design.md`.

**Architecture:** A single new `.astro` component next to `Button.astro`, reusing the existing `.btn`/`.btn-primary`/`.btn-secondary`/`.btn-ghost`/`.btn-error` CSS rules already in `app/src/styles/global.css` — no new CSS. `aspect-square` + `rounded-full` guarantee a perfect circle regardless of caller-supplied padding; `border-3` is the base border width for every variant.

**Tech Stack:** Astro component, Tailwind v4 utility classes, `cn()` (`app/src/lib/client/cn.ts`) for class composition.

## Global Constraints

- File location: `app/src/components/forms/IconBtn.astro` (component files never live loose under `pages/`; `components/forms/` is the existing home for standalone action elements).
- Variants: exactly `primary` | `secondary` | `ghost` | `error` | `dashed` (same five as `Button.astro`), default `primary`.
- `ariaLabel` is a **required** prop (not optional) — no text fallback exists.
- No built-in padding — padding comes entirely from the caller's `class` prop.
- Base classes always include: `flex items-center justify-center aspect-square rounded-full border-3`.
- `dashed` variant additionally sets `border-dashed`.
- One default (unnamed) slot only — no `iconBefore`/`iconAfter`, no `loadingExpr`, no `title`.
- Build-time class composition via `cn()` only — never `class:list` (`scripts/check-astro-class-composition.sh`).
- No `font-medium`, no `{...rest}` (use `{...props}`), no Tailwind important modifier in either form (`scripts/check-style-tokens.sh`).
- `.astro` markup logic stays inline in the component's own frontmatter — no extracted helper file, and no unit test is required for it (D101); this applies to `IconBtn.astro` itself.
- Reuse `.btn`/`.btn-primary`/`.btn-secondary`/`.btn-ghost`/`.btn-error` from `app/src/styles/global.css:278-340` — do not add new CSS.
- Prettier + `prettier-plugin-astro` formatting (`singleAttributePerLine: true`) must be clean before commit (`cd app && npm run format`).

- [ ] **Step 1: Write the component**

Create `app/src/components/forms/IconBtn.astro`:

```astro
---
/**
 * Icon-only button — always a perfect circle. Unlike Button.astro, this
 * never renders text: pass the icon as the single default slot.
 * @param {"button"|"submit"|"reset"} [type]
 * @param {"primary"|"secondary"|"ghost"|"error"|"dashed"} [variant]
 * @param {boolean} [disabled]
 * @param {string} ariaLabel Accessible name — required, there is no text fallback
 * @param {string} [class] Extra classes; padding/sizing lives here, the component applies none
 */
interface Props {
  type?: "button" | "submit" | "reset";
  variant?: "primary" | "secondary" | "ghost" | "error" | "dashed";
  disabled?: boolean;
  ariaLabel: string;
  class?: string;
  [key: string]: unknown;
}

// Props
const {
  type = "button",
  variant = "primary",
  disabled = false,
  ariaLabel,
  class: classNameProp = "",
  ...props
}: Props = Astro.props;

// Lib
import { cn } from "@client/cn";

// Styles
const variantClasses = {
  primary: "border-transparent bg-white text-black btn-primary",
  secondary: "border-border text-foreground btn-secondary",
  ghost: "border-transparent text-muted-foreground btn-ghost",
  error: "border-transparent bg-error text-error-foreground btn-error",
  dashed: "border-accent border-dashed bg-transparent text-muted-foreground",
}[variant];

const className = cn(
  "btn flex items-center justify-center aspect-square rounded-full border-3 transition-[transform,color,background-color,border-color,box-shadow] duration-150",
  variantClasses,
  classNameProp,
);
---

<button
  type={type}
  disabled={disabled}
  aria-label={ariaLabel}
  class={className}
  {...props}
>
  <slot />
</button>
```
